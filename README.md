# Linux DAW Popularity

## Intro

There has been an explosion of plugins added to LinuxDAW in 2026, as a result of easy access to coding agents. While some LLM-assisted plugins can be genuinely useful, the massive proliferation of similar plugins from unknown developers isn't of interest to most Linux audio users. What's worse, is that this huge volume crowds out the truly exciting Linux audio renaissance going on right now; developers who have a lot of happy users in Windows/Mac land are coming out with Linux versions of their plugins all the time, and it's almost impossible to see them on LinuxDAW.

At present, there is no easy way to search LinuxDAW and see "what are some plugins recently released on Linux worth checking out?"

This repo is my attempt at a proof of concept solution for this problem. 

My first pass involved looking up the popularity of the domains marked for each plugin. A free source for this is [Tranco](https://tranco-list.eu/). Although Tranco is focused on cybersecurity, its database is more generally a measure of 'popularity'. Its API has about 5 million domains, so inclusion on this list means "This is one of the top 5 million domains". I figure this is a good first step at figuring out whether or not a plugin comes from an "established" developer.

Looking at the results of this analysis made me a bit sad though; some established Linux plugin developers are left out! So I added a second criteria based on the plugin's `created_date` field in LinuxDAW. *Did this plugin developer release any plugins for Linux before 2026?* The created_date field is an imperfect indicator of this, as it's the date that the plugin was added to LinuxDAW, not the date the plugin was released. But I've been using LinuxDAW long enough to be happy with this as a proxy; it's been generally well-updated for at least a year.

## Shortcomings

This still misses some. I know of *Septabee* offhand, which kind of made its own splash. Or Dusk Audio! I happily use Dusk Audio plugins (which are LLM-assisted, but to me are still high-quality plugins). I don't think new domains make it into Tranco that quickly. It is true that new plugin developers need to figure out how to make a splash on their own. It's tough, but fair when there's this much to wade through.

This is just a prototype so far. Ideally, I'd like to see functionality like this incorporated into LinuxDAW.
